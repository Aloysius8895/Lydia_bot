# 界面与知识库

## 用户已经选定的设计习惯

正式 UI 使用原有 React/Crew 设计演进，不退回另写的原生页面或独立绿色／米白 Crawl 站点。后续选定暖米灰白天、纯黑夜间，组件一致，保留用户已有内容、头像和工作流程；旧截图的颜色／字号不自动覆盖最新决定。

新的视觉方向按用户要求先在 `pic/<主题>-<日期>` 制作可查看的整页、相关组件、桌面／手机、白天／黑夜预览，必要时视频和 proposed 补丁；明确标设计稿／已实现。用户已批准的方案直接落地，不重复走确认。布局拥挤优先独立页面／分层，避免把所有操作挤进右栏。

生产源在 frontend/src，main.jsx 引入样式，Vite dist 才是服务内容。源码已改但页面未变时查端口／任务、dist manifest、当前 JS/CSS 哈希、SW／缓存，不盲目重复改 CSS。

三栏 27/42/31 是旧基线，最新已经允许主页面与知识库侧栏分别拖宽记忆。`panel-resize.jsx/css` 提供鼠标、键盘、双击恢复、Esc 取消及最小中区；桌面／知识库分别 localStorage，手机不显示分隔条。分隔线 z-index 不能盖住折叠／设置按钮。

手机单栏／抽屉，底部液态玻璃导航，安全区与列表末尾留白，短高度也不能挡 Bob 等末项。触屏拖放采用长按后拿起资料，防白块、位置偏移、系统文字选择；处理 pointer capture、scroll、取消与 drop 命中。缩放支持双指；桌面点击、拖放不能因此失效。

## 知识库与 Idea 实验台

知识库单独工作区，返回「商业逻辑」回原 Lydia；书库／新闻／idea／工作台按现有路由，不复制第二份业务状态。3D 风格资产保持可追踪源文件，Blender .blend／导出与离线预览见 pic 的 BLENDER_ASSETS；工具可用性重新确认，不假称 Blender MCP 已连接。

IdeaLab 选 2–6 条不同的作品或新闻，存来源 UUID、版本／revision、实际正文片段、限制和用户约束；请求键与输入哈希保持幂等。只比较选中的资料，逐字 quote 必须出自相应来源；每个涉及的来源都需引文。新闻和作品混合时每个 idea 同时引用两类并解释 news_angle；不能硬拼，允许零候选。

summary_only、正文不足或 SOCIAL_POST 拒绝进入需要全文的比较。默认约三个、最多五个 idea，说明借鉴、差异、适配、MVP、假设、第一验证动作，全部待验证。收藏到专门书架才是用户保留，不自动成为市场成功事实。服务重启中的分析标 interrupted，避免自动重复花订阅额度。

## 简介与深入解读

`project-brief.ts` 后台串行生成「问题／方案／如何实现」，用户意图是新项目先生成简介再展示；当前 knowledge.ts 的 BRIEF_GATE 具体允许 ready 或 failed 后显示，并有 24 小时兜底，防止永久隐藏。书库和搜索使用同一 gate，不能把用户意图误写成「没有成功简介就永远不显示」。老简介升级时按现有代码兼容显示。所有简介改为附原文并由程序核对，GitHub 链接取 README 原文。

`project-sources.ts`／`project-deep-dive.ts` 按用户点击读取真实项目页、最多两个公开 GitHub 仓库信息／README／文件树及少量 manifest。当前代码上限：项目页最多 3 个、每页 30000 字符；README 40000、manifest 4000、文件树 250 路径。登录页面、私有仓库、限流／失败保留日志，不猜内容。额度和上限可能演进，执行前读常量。

深入解读分 problem、usage、architecture、details、evidence：每条附 1–3 段逐字原文，程序查是否存在、必要时修正来源号；找不到删除；Haiku 再判断 full／partial／none，none 删除、partial 标黄。字面核对只是出处证明，语义审核也是模型判断，均不保证来源属实。不得写不存在的功能／客户／奖项，不打分或硬写借鉴评价；未知单列。

只按点击生成深入解读，结果持久化，重新解读再抓资料；关闭面板后台继续、换项目关闭、Esc 可退。它是阅读辅助，不自动写成市场证据。迁移 `012-project-deep-dives.sql`，测试 deep-dive / project-brief。

## 本地资料搜索

`library-search.ts`、`POST /api/knowledge/search` 查询本地资料，不自动联网。Enter 才触发，输入时不筛库；多个搜索区并存，最多五个，删除可归还书本、原位留虚线空位。只保留书飞来所需动画，不加星光／翻页等用户已删特效。搜索区在本设备记忆，刷新不重播；新项目可见性按上面的 BRIEF_GATE。Claude 辅助挑选本地候选仍使用订阅额度，失败降级关键词；「本地搜索」不等于完全没有模型调用。
