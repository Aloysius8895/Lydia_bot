## 本轮只调整视觉

- 底部仍为「会话 / 项目 / 设置」。参考第一张图：白色悬浮胶囊外壳，黑色选中项显示图标和文字；未选中项显示灰色图标。底部三个入口的含义和去向不变。真实实现时，图标仍需提供完整可访问名称。
- 整体参考第二张图：炭灰底、深灰圆角面板、浅蓝与淡紫卡片、柔和边界、简洁字体与留白。浅色用于项目选择、团队入口、当前标签和语音条，避免整页深灰难以分层。
- 不引入金融内容、银行卡、余额、支出图表、销售指标或装饰奖项。
- 保持上一版的六屏内容、文案、专家、示例项目、资料分类、数字、任务状态及布局职责。
