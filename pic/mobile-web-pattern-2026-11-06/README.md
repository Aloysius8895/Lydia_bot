## 视觉依据

参考当前实际 Web 截图 [desktop-light.png](../implemented/desktop-light.png)，并对照 `business/frontend/src/soft-workspace.css` 和当前 MobileHome、SettingsModal、Avatars。继承灰紫底、白色面板、细边框、柔和圆角、低强度阴影和原有彩色角色。

| Web | 手机设计 |
| --- | --- |
| 左侧导航与专家列表 | 会话首页；底部三个主入口；聊天左上角返回 |
| 中间对话面板 | 专注聊天屏；顶部保留角色、当前项目与研究阶段 |

| 通话入口和输入框 | 同样结构；软键盘打开时压缩辅助区，保留编辑与发送空间 |

## 方案取舍

1. **推荐：同源面板 + 职责拆分（本稿）。** 保留 Web 的会话/聊天/研究结构，手机每次呈现一个主要任务。需要补齐导航和面板过渡。
2. 仅改配色、圆角、字号。工作量较小，但手机现有的横向设置分类和入口组织不会改善。
3. 项目仪表盘首页。适合跨项目浏览，但让日常找专家、继续聊天多一步，偏离目前 Web 的使用习惯。

## 待确认后的实现约束

- 调整手机布局与导航，桌面三栏、业务 API、项目资料和身份权限沿用当前逻辑。
- 保留全部功能：新建/切换项目、专家/团队会话、资料分类/检索、Gap 明确选择、企业要求、任务暂停/恢复/取消、通话、Crawl 和完整设置。
- 新建项目入口为首页 +；Crawl 在设置的工作区组；资料入口为聊天右上角详情中的资料标签。底部项目入口跳转现有项目库。
- 详情默认保留关闭按钮与点击操作。向下关闭的手势是候选交互，需在实现时验证滚动冲突，静态稿不证明手势已实现。
- 聊天页不放底部主导航，给输入区和软键盘留出空间。考虑 iPhone safe area、动态视口、键盘遮挡与滚动恢复。
- 正文目标 16px；角色列表 16px；主要触控目标至少 44×44。本稿注释与辅助标签偏小，落地时需按真机阅读调节。
- 头像使用现有角色，不替换用户定制头像；已自定义时仍由当前配置渲染。
- 图中“跟随设备”为设置样例，外观最终沿用当前已支持的主题选项，新增自动跟随需另行明确。
- 无资料/失败/离线/登录过期状态保留可读提示；项目 brief 不冒充 MARKET 需求证据；通话未接通时不显示实时波形。
