LYDIA / MOBILE WORKSPACE / DESIGN PROPOSAL 01

同一个工作区，更适合单手使用。

沿用 Web 的柔和底色、白色面板、淡紫选中态和彩色角色。
把三栏的职责重新组织到手机：会话首页 → 专注聊天 → 研究详情。

与现有 Web 共用视觉语言
现有 Web 实际界面 · 视觉依据

01 / 保留 Web 的熟悉感

角色、圆角面板、分组列表、分段控件和输入框保持同源。没有增加数据仪表盘或重新定义专家身份。

02 / 重新安排三栏的职责

左栏成为会话首页；中栏成为聊天主屏；右栏成为可展开详情。聊天内不放底部主导航，给内容和键盘留出空间。

03 / 手机专属的阅读节奏

单一项目入口、44px 触控区域、16px 正文目标。设置采用纵向分组，研究页的四个标签在一屏内可见。
