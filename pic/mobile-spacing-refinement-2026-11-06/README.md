## 调整

1. **导航不压内容。** 首页和设置的内容区在底部导航上方结束，可独立滚动；列表结尾另留 25px 内边距。玻璃导航仍保留在底部。截图的首页特意滚到列表末尾，确保 Bob Moesta 的姓名、说明都完整可见。
2. **聊天底部只保留输入框。** 将大块的语音卡片移为聊天顶部电话图标，点击展开保留「语音通话 / 与 Steve 继续讨论 / 开始通话」。静态参考里的确认按钮不接通通话。
3. **任务状态降低视觉重量。** 仍位于消息内容区，保持原有状态文案，用细分隔线和文字替代胶囊底色。用户仍可在未来实现中展开任务操作。
4. **保留输入区留白。** 输入框上下增加空隙，发送和附加入口保持清晰；真实实现还需结合 iPhone safe area 和软键盘动态视口验证。

专家、对话、项目、资料、任务状态和三个导航入口均保留。旧稿保持原样；本轮仅写入 pic，正式应用未修改。由于通话说明改为按需展开，默认截图不再显示整张语音卡片，功能入口仍在。
