## 布局与信息

顶栏：Lydia、知识库名称、搜索与导入入口。
左栏约 19%：集合、项目与搜索筛选。
中央约 57%：等距研究图书馆、分区标签、选中状态、缩放和总览。
右栏约 24%：选中文件的用途、来源、版本、摘录与打开操作。

这是专用知识库面板的设计比例，不改变现有聊天三栏布局。

空间使用三个分区：PROJECT（项目背景与约束，蓝灰）、MARKET（市场来源材料，暖白）、METHOD（专家方法，淡紫）。颜色配合文字，不单独承担含义。MARKET 只表示用途，不保证事实已经核实。PROJECT 和 MARKET 继续按案件隔离，METHOD 沿用全局方法与角色过滤。

一份资料对应一个物件，资料集合对应架组。数量增加时按组聚合，不把每个文本片段变成模型。物件表达组织关系，正文、来源和判断依据在可读 UI 面板中展示。

## 交互设计

- 初始显示项目总览；选择区域后聚焦，随时返回总览或重置视角。
- 空间与列表两种视图共享筛选和选择；列表负责精确查找、排序和键盘访问。
- 点击物件打开右侧详情；hover 只显示简短标题，正文不贴在模型上。
- 青绿色描边和底座标识选中资料，普通物件保持中性外观。
- 搜索结果在列表中可读，并定位对应分区；不将相关性表示为真实性。
- 手机默认分类与资料列表，空间浏览为可选全屏，详情用底部面板。
- 空库引导上传或添加公开 URL；空搜索提供清除筛选；失败状态提供重试。
- 无 3D 支持时仍可使用列表；减少动态效果时关闭镜头补间。
