# iPhone 安装 Lydia

2026-11-06。电脑端实现与真实 iPhone 验收分开记录。

## 启动和证书

1. iPhone 和电脑连接同一个可信 Wi-Fi。先正常停止其他 Lydia 服务，双击 `business/Start-Lydia-Phone.cmd`。保持终端运行；Ctrl+C 正常停止。
2. 启动器选择私有 IPv4、验证证书并构建界面。多网卡时，在 business 中运行 `node --experimental-strip-types scripts/start-phone.ts --host <电脑IPv4>`。当前地址可能变化，以终端输出为准。
3. iPhone Safari 打开终端显示的 HTTP 证书下载入口（端口 4319）。核对页面与电脑终端的 SHA-256 指纹，下载 `lydia-local-ca.cer`。此端口只提供引导页和公开 CA，无私人资料和登录入口。
4. iPhone「设置 → 通用 → VPN 与设备管理」安装描述文件，再到「设置 → 通用 → 关于本机 → 证书信任设置」，开启 `Crew Personal Local CA` 完全信任。名称沿用现有 CA，以保留已安装证书的一致性。
5. Safari 打开终端显示的 HTTPS 地址（端口 4318），确认无证书警告后登录。已有密码继续使用。首次密码仅可在运行服务的电脑设置，至少 12 字符。若电脑尚未信任该 CA，可打开 `deployment/certs/crew-local-ca.cer`，按 Windows 证书向导安装到本人当前用户的「受信任的根证书颁发机构」，核对同一指纹后重新打开 HTTPS。程序不自动修改系统信任库。
6. Safari 分享 → 添加到主屏幕；如有「作为网页 App 打开」，保持开启。从 Lydia 图标重新打开。

## 真机验收

- HTTPS 页面无证书警告，工作区密码登录成功。
- 从主屏幕图标打开，设置 → 手机显示「主屏幕独立窗口：已检测到」。
- 已有项目能打开，刷新或退出再打开后仍可恢复。
- 上传一份自己的 TXT/MD 资料，确认索引与检索可用。
- 运行本人需要的任务，检查暂停、恢复、取消与重连。真实推理会使用已有 Claude 订阅额度。
- 关闭电脑服务时显示不可连接；缓存页面不代表后台继续工作。

麦克风与语音识别能力单独验收，不由主屏幕安装成功推断。

## 无法打开时

确认不是访客 Wi-Fi、手机未使用隔离网络，且电脑 IP 未改变。Windows 防火墙可能阻止设备入站。仅在确认当前 Wi-Fi 可信后，为当前电脑地址的 TCP 4318、4319 添加限制远程范围为 LocalSubnet 的入站规则；不要关闭整个防火墙。当前网络被 Windows 标记为 Public，安装器不会自动改分类或规则。若系统要求管理员授权，需要由电脑用户操作。更换网络后重新启动；多网卡需指定 --host。

端口被占用时启动器拒绝继续，避免两个服务同时读写数据库。不要直接启动第二个实例。HTTP 4319 不提供研究服务；HTTPS 4318 才处理登录和项目。

重复启动：启动器会核验运行中 HTTPS 和同一公开 CA 下载入口；确认是已有手机服务时，显示“已在运行”，本次直接退出，不重新构建或启动。其他端口占用则提示先停止原进程。端口检查使用实际 LAN 地址与排他绑定，修复 Windows 下通配地址预检查漏报的问题。

官方说明：[Apple 证书信任](https://support.apple.com/102390)、[Safari 添加主屏幕](https://support.apple.com/guide/iphone/iphea86e5236/ios)。
