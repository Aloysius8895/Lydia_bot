# Twitter 来源扩展设计

状态：用户于 2026-11-06 授权「开始执行」。现有代码接入已实施；构造样本与浏览器验证通过。真实账号的线上采集未验证，现有 robots 策略仍可能阻断。验证记录见 `crawl/docs/TWITTER_VALIDATION.md`。

## 范围

在现有 `crawl/`、共享后端及 CrawlSettings 增加来源，不创建另一套爬虫服务或数据库。复用任务、快照、去重、版本、证据、导出和现有案件导入接口。

用户可指定一个账号或一个关键词查询创建批次。第一版默认最多 50 条、10 次滚动，受现有时间和字节预算约束；支持调整限制。账号输入只接受有效 handle，查询通过 URLSearchParams 编码。默认查询使用最新结果，明确提示不保证覆盖历史全量。

## 获取与登录

使用单独的本机持久浏览器 profile，位置为忽略提交的 `.runtime` 子目录。首次通过本机操作打开登录窗口，由用户自行登录；后续任务复用该 profile。登录窗口与采集共用互斥锁，避免 profile 被两个进程同时打开。不复制日常浏览器 Cookie，不将 Cookie/Authorization 写入 API、日志、快照或导出。

登录入口仅限本机授权访问；沿用既有认证、Origin、CSRF 防护，远端请求不能弹出服务器桌面窗口。服务退出关闭自身 context，保留 profile。

现有 robots 策略继续生效。当前 X 的通配规则会使账号和搜索请求受阻。第一版必须诚实显示该状态，不能为了展示成功而跳过检查。若希望改变这项项目既有策略，需明确修订设计；当前设计不包含该变更。

## 页面解析

候选选择器和证据边界见 `crawl/docs/TWITTER_STRUCTURE_ANALYSIS.md`。每轮滚动收集当前卡片，按字符串推文 ID 累积；请求详情时匹配目标 ID，排除回复与引用内容污染。选择器不匹配时报未知模板，不产出猜测记录。

记录字段为 ID、规范原文链接、作者 handle/显示名、原始正文、发布时间、采集时间、原始可见互动显示、外链和媒体说明。未显示字段为 null；折叠正文标记不完整。截图或 HTML 诊断仅保存内容页必要范围，不保存登录表单或账户管理页面。

## 存储与语义

沿用共享 crawl 记录及版本表，meta 明确 `record_kind=social_post` 和 `source_nature=SOCIAL_POST`。推文 year 取真实发布时间，不套用赛事 year_basis；无时间则未知。无赛事、奖项和入围关系。按 source + tweet ID 幂等，内容改变保留版本。互动采集时间与内容时间分开。

案件导入保留 SOCIAL_POST 和 author_claim；不把作者陈述自动作为已核验需求。导出沿用 JSON/CSV/Markdown，保留身份、出处和可见范围限制。

## 任务行为

复用持久队列、领取令牌、续租、暂停、继续和取消。浏览器循环每轮检查取消/暂停，下一轮前退出，释放 profile；已完成的快照提交仍需有效领取令牌。重启后按原查询重扫并去重，不承诺稳定的网站 cursor。

登录失效、验证、robots 限制、未知模板和不可见内容返回明确 blocked 原因；429 及临时错误按现有次数和退避重试。达到条数、滚动或时间预算记 partial，不宣称全量；实际为空与无法访问分开。

## 验证

构造样本验证 ID 精度、作者/引用隔离、媒体贴、缺失指标、年份、重复去重、URL 边界和未知模板。临时数据库验证新增来源、任务状态、版本及导出。模拟浏览器验证多轮 DOM 回收时累积不丢贴、锁释放、预算和取消。运行 TypeScript 检查、爬虫相关回归、前端构建。

真实浏览器验证需要用户完成专用 profile 登录，并满足现有访问策略。若访问受阻，报告阻断而不把构造样本测试当成线上采集成功。
