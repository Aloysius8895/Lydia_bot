# Lydia 参考图比例与字号

用户要求依据新的桌面/手机参考图调整文字和旁边窗口大小。参考图桌面应用区域约1388px宽，左栏约378px、聊天约575px、右栏约435px，采用近似27% / 42% / 31%。这是应用内容区比例，不包含图片里的蓝色背景、手机外框或系统窗口装饰。

桌面宽度大于1180px：左栏固定占27%，打开右侧工作区时右栏31%，聊天区取余下42%；关闭右栏后聊天自动展开。列表名字18–20px、说明15–17px、消息18–20px、右栏正文17–19px、辅助16–18px，根据窗口宽度平滑变化。保持颜色、头像、主题和功能。

761–1180px：保留左栏与聊天，工作区采用430px以内浮层。手机不显示桌面左栏，工作区宽度不超过视口，保持列表/聊天单栏。允许纵向滚动，不允许横向溢出。

验证宽度1388/1440/1920的真实三栏比例、1024平板浮层与390手机布局，保存截图和计算后的字号/宽度；复用既有18项浏览器流程，并增加比例检查。独立TEST_ONLY数据库，不进行真实推理。
