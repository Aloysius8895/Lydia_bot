# Lydia 字号放大

用户提供研究设置面板与整体桌面截图，要求放大偏小的文字。本次使用既有组件与主题，只修改 research.css 的排版覆盖，保持原设计 styles.css 和研究行为不变。

设置面板：标题18px、页签/分组标题14px、辅助文字与状态15px、正文/按钮/主题开关16px；面板桌面宽度由340px增至380px，窄屏宽度不超过视口，保留纵向滚动。侧栏姓名17px、说明14px；聊天标题20px、消息/输入17px，选择框16px。间距和行高同步调整，长状态允许换行。

构建后通过既有浏览器流程确认深浅主题、按钮可操作和390px手机布局，查看桌面/手机设置截图，记录实际计算字号及水平溢出检查。无需新依赖、真实模型调用或改动案件数据。
