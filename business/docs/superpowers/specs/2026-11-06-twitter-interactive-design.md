# 本机自动浏览 X 修订

用户在 2026-11-06 明确要求自动浏览自己登录的 Twitter 并查找内容，随后在专用浏览器尝试登录。因此新增显式 `transport: interactive`，作为界面默认选项。

该路径直接使用本机持久登录窗口，显示浏览器并读取账号页和关键词页；不经过匿名 HTTP 预取或旧的机器人 robots 分支。原 `browser` 配置继续保留 robots 检查，既有批次不会自动变成 interactive；API 保留可选，不是自动浏览的前置条件。

首次登录由用户在 X 页面手动完成，凭据不进入聊天或程序配置。Google 登录可能拒绝自动化浏览器；可由用户选择 X 的用户名/邮箱/手机号登录。程序不修改浏览器安全保护、伪装自动化标志或绕过验证。

采集阶段仅允许 X 和必需静态域的读取请求；不自动发帖、关注、点赞或发送消息。遇到登录失效、验证码或限流会明确停止。单轮、总量、时间、字节预算及原队列控制继续生效。

真实检查用专用 profile，最多 3 条推文与 2 次滚动。没有实际观察到推文时，不宣称已完成真实采集。登录脚本和真实检查脚本分别为 `crawl/scripts/twitter-login.ts` 与 `crawl/scripts/twitter-check.ts`。
