# 参考图角色头像

用户指定彩色几何角色图片为头像依据，直接在现有 SVG 头像组件中实现，无新增图片生成、下载或依赖。

采用颜色到角色的稳定映射：Steve 蓝色软方块、Ash 橙色圆形、Teresa 青绿色软方块、April 粉色圆角三角、Bob 紫色菱形；个人头像为黑色角色。额外配色支持黄色云朵、灰色水滴、棕色圆形。所有尺寸复用向量轮廓和浅色眼睛，团队与堆叠头像使用实际小角色；黑色角色在深色主题增加细轮廓。

沿用用户已明确选择的参考风格，不修改研究行为、角色身份或主题切换机制。修改 Avatars.jsx、个人头像调用和局部 CSS；构建并通过现有浏览器检查，目视核对桌面、手机和深浅主题截图。历史原设计哈希报告保留原时间，新增记录说明此次头像是用户授权的后续修改。
