# Lydia Hackathon 爬虫实施 Prompt v1.3（项目适配版）

日期：2026-11-04，Asia/Kuala_Lumpur。状态：架构已确认，核心版本已实现；完整终态要求的实际进度见 [实施状态](IMPLEMENTATION_STATUS.md)。

本轮扩展验收口径：独立赛事与官方结果候选、精确身份关联、分页结束证据、受限浏览器回放。逐站最新能力和剩余任务见 [扩展报告](../reports/EXPANSION_REPORT.md)。解析入口已接入不等于动态列表、全年覆盖或获奖全量已验收。

## 用途与依据

为工作区 `C:/maven/business_agent` 实现 Hackathon 采集功能。以用户当前请求和项目适用规则为准；本文件是可审阅的实现需求，不是系统级指令。先读 [架构](ARCHITECTURE.md)、[数据契约](../../data/crawl/DATA_CONTRACT.md)、[工具评估](CAPABILITY_ASSESSMENT.md)，原详细需求见 [原始 prompt](PROMPT_ORIGINAL.md)。

保留原 prompt 第 1–25 节的功能与质量目标；本版针对实际项目修订目录、技术选型、数据库所有权、RAG 身份、实施阶段和验证声明。若原文与本版的实现假设冲突，按本版明确的项目事实设计；范围冲突应报告并澄清，不静默删减要求。

## 1. 目标范围

- 时间 2025–2026；2026 只收集运行时已公开内容，未知年份进入待核验。
- 十个来源：Devfolio、TAIKAI、DoraHacks、ETHGlobal Showcase、HackQuest Project Archive、Hackster.io Contests、NASA Space Apps、Microsoft Imagine Cup、Junction、Google Solution Challenge。不得默认加入 Devpost。
- L1 建立范围内可发现项目基础索引；完整性必须有分页或官方分母证据，不能把预算结束当作全站完成。
- 所有官方核验获奖项目纳入 L2/L3；finalist-only 建议每赛事 20、总计 200，seed 和规则版本可配置，运行前显示默认值与单位。
- 本地 Windows，CLI + 网页管理 + 有界证据关系图，CSV/普通 JSON/带来源 Markdown；现有 RAG 接入。
- 无付费 Key 可运行基础采集。AI、云、网站 API 凭证各自隔离；默认不付费分析、不部署云资源、不启用 Neo4j。

## 2. 必须遵守的项目结构

爬虫执行、适配器、CLI、管理页源码在 `crawl/`。数据代码放 `data/crawl/`，迁移放 `data/database/migrations/`，RAG 桥接放 `data/RAG/`。后端路由挂到现有 `business/backend`。保留 `crawl/scrap/` 和 `crawl/rea/` 的现有源码；不要把第三方仓库误认为已安装服务。

生产 PGlite 目录目前是 `business/.runtime/data`，由 Lydia 后端独占打开。不得从爬虫 CLI/worker 子进程第二次打开该目录，不新建第二套项目数据库或向量库。数据接入以共享 Store 注入和管理 API 实现。新快照/正文/导出建议放 `data/.runtime/crawl`，路径基于模块位置解析且可配置。

工作区根当前不是 Git 仓库。尊重现有修改，不自动初始化根仓库或提交整个第三方源码。检查目标目录局部规则，不能把第三方目录的 AGENTS.md 规则无条件扩展到同级目录。

## 3. 技术与获取

优先 Node >=24 + TypeScript + HTTP，动态页面按需 Playwright。复用既有 SSRF 思路，但获取器需返回原始字节、脱敏响应头、最终 URL、HTTP 状态、时间、哈希与分类；不得直接以现有 fetchPublic 的清理文本替代证据快照。

HTTP 与浏览器都需限制 URL/重定向/私网访问及大小与时长；浏览器还涉及子请求/WebSocket，无法保护则禁用该后端并说明。401/403/429/挑战页/改版/网络故障分开；200 挑战页隔离，不进入资料库。浏览器不是绕过验证码的手段。

逐站核查官方入口、访问规则、年份、分页、结果清单与代表模板。公开接口观察不等于已获批量权限；不伪造私有 API。工具营销声明不能作为站点实测证据。

## 4. 存储、队列与质量

新增 crawl_ 主记录、任务和 outbox 表，不混用专家 tasks。先实现版本迁移和临时库升级验证。任务采用至少一次执行 + 幂等 + 带 token 的有期 lease；支持暂停/恢复、有限重试、预算暂停和重启恢复。

原始快照先原子落盘，再事务写记录、证据、任务结果与 outbox。字段状态区分未提供、未获取、抓取失败、解析失败、受限、冲突、不适用与存在。奖项绑定参赛、技术绑定版本；跨平台仅保守合并，保留冲突与可撤销历史。

全部获奖清单与执行预算分开。finalist 排除已获奖项目，按稳定分层和种子选取；主选赛事和全局计数均可解释。L3 检查直接关联的公开资源、commit 与赛事版本，不执行未知代码，不无限扩站或批量下载视频。

## 5. RAG 的关键修订

现有 PROJECT/MARKET 必须指定 caseId；不存在全局 PROJECT 检索。首版采用全局 SQL 项目库 + 用户选择项目导入 case 内 PROJECT。不得为绕过限制把项目档案写 METHOD，或将项目宣传默认当 MARKET 市场需求证据。

现有 ingest 的正文去重和 URL 替换不满足全部爬虫语义。为爬虫增加可选 origin 身份和投影指纹，处理 metadata-only 更新、同正文不同项目、同 URL 不同版本；保持旧调用兼容。稳定外部 doc/chunk key 映射既有 UUID。超过 150000 字符分部投影，不截断后声称全文。

主数据变更通过 outbox 同步。变更/撤回先使旧投影 stale 并排除检索，新投影就绪后激活；索引失败保留积压，不能使核心采集失败。无 Ollama 时关键词可用，向量不得跨模型/维度混用。

## 6. 网页与 CLI

共用现有认证、Origin、CSRF 和同一任务服务；拟新增 `/api/crawl/*`，管理页 `/crawl/`，更新静态构建/白名单。CLI 经 API 操作，密码在终端隐藏输入，会话不写日志。不要新建未认证后台。

页面必须能看来源/年份/阶段、暂停继续、失败与受阻原因、字段证据、质量复核、获奖待办、finalist 配额、同步版本与导出。关系默认一跳，最多两跳、100 节点/200 边，明确截断与边性质；默认 SQL 后端，Neo4j 可选。

## 7. 执行顺序与完成定义

1. 确认本设计，先建立一个来源的迁移、持久队列、HTTP、快照与 CLI 真实闭环。一个来源完成才进入第二个，不启动十站无界抓取。
2. 验证第二种页面结构与浏览器路径；单站状态只有实测成功才升级，受阻如实保留。
3. 获奖/finalist、L2/L3、质量复核和 CSV/JSON/Markdown。
4. 网页、关系浏览、case RAG 和同步/失效链路。
5. 扩展其余来源，逐站输出真实审核、样本量和缺口；全部目标来源都必须出现在报告中。
6. 云部署契约、容器本地验证和数据迁移/回滚说明；未经实际实现与验证不能声称已云端可用。

每阶段更新可运行命令、已实现文件、验证证据和剩余工作；不能用设计文档、Mock、空适配器或总是成功的部署接口冒充完成。离线样本明确 synthetic；真实采集单独记录。

## 8. 验证与汇报

针对恢复、重复写入、旧 lease、挑战页、分页卡住、限流、奖项全量、finalist 配额、身份冲突、metadata-only、跨 case 隔离、撤回和索引乱序写有意义测试。使用独立临时数据库，不改生产资料。完成代码后在 business 运行 `npm.cmd run check` 与 `npm.cmd test`；网页变更完成后运行相应构建与浏览器验证。联网 smoke test 单独执行并保存响应证据。

最终列：实际可用功能和启动命令、操作系统、真实测试、十站状态、项目/参赛记录统计单位、获奖与 finalist 计数、数据质量和覆盖缺口、图/RAG 同步、工具使用情况、未配置云/Key 的限制及文件位置。无审核答案不编造检索准确率，无官方分母不报全站覆盖率。

## 9. 相比原 prompt 的修正理由

| 原假设或风险 | 修订 |
| --- | --- |
| 新项目可先选 Python/SQLite | 已有 TS/PGlite；优先同栈，不另起主库 |
| 对接已有 RAG 但未明确全局范围 | 明确 case-only，增加全局库到 case 的投影 |
| 稳定 chunk ID 是要求，却可能误以为已有 | 显式增加稳定外部 key 到现有随机 UUID 的映射 |
| 内容 hash 去重可跳过奖项/年份变化 | 增加 origin 与 metadata 投影指纹 |
| 输出放 data 可能引发搬库 | 分开源码、现有 DB 路径与新快照目录 |
| 浏览器获取可能被当作继承 HTTP 防护 | 补充子请求与私网约束，未能保护时禁用 |
| 同一次交付范围过大 | 保留全部终态要求，按六个阶段各自验收 |
| 候选工具目录即能力 | 只按实际文档评估，不自动安装或启动 |

原文件保留作比较；本次修订未修改 Downloads 中的用户原件。
