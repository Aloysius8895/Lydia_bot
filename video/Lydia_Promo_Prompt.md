# Lydia 宣传片提示词：数据库 + 商业逻辑

写于 2026-11-12。依据有四样：同目录的三份参考提示词（Holo、AI Foundation Lab、Teamflect）、`skill/video-shotcraft` 的制作规则和镜头卡、Lydia 当前的代码，以及 `pic/` 里的实际截图。

## 0. 这份文件怎么用

- **给谁**：负责制作的 AI（装了 video-shotcraft 的 Claude Code）或动效设计师。用户先审，确认后才进入素材采集和制作。
- **制作模式**：按 video-shotcraft 的「共同创作」走。这份文件就是阶段 0–3 的产物，包括产品简报、视觉方向、功能到镜头映射和分镜。用户确认后，从 `references/pipeline.md` 阶段 4（最终素材采集）开始制作，不再重新设计。
- **哪些是事实，哪些是建议**：
  - 功能描述、界面文案、配色值、专家顺序都从 Lydia 代码和截图核对过。
  - 时长、帧数、缓动、构图是建议，以参考样片和 demo 源码为准。
  - 标着「待定」的，要用户决定。
- **三份参考片各借什么**：
  - Holo：开头的大字快节奏钩子，"Meet → 品牌"那一下安静的停顿，以及左侧列表逐项高亮。
  - AI Foundation Lab（它就是 video-shotcraft 的 Ink Press 模板片）：暖纸底，标题页和界面演示交替，卡片推进到详情页，文档自己写出来，品牌首尾呼应。
  - Teamflect：浅 3D 的 UI 分层，大号黑色鼠标引导点击，连接线。
- **不借的东西**：
  - Holo 的彩色渐变、机器人、金额柱状图：Lydia 界面里没有这些，而且不能编数字。
  - Ink Press 的衬线字和棕金色：按 video-shotcraft 核心规则 2，视觉要从产品自身长出来。

## 2. 需求到执行决策

## 3. 视觉方向：白天暖纸，黑夜书库

一句话主张：**白天讲怎么想，黑夜讲资料从哪来。**

Lydia 本身有白天和黑夜两套主题（太阳 / 月亮按钮），所以片子也分成两章。开场和商业逻辑段用白天，数据库段切到黑夜，切换动作本身用 Lydia 的主题按钮来做。

### 颜色 token（取自 `business/frontend/src/warm-theme.css`、`knowledge.css`、`match.css`、`avatarKit.js`）

| 用途 | 白天 | 黑夜 |
|---|---|---|
| 背景 | `#f3f2ef` | `#080808` |
| 卡片 / 面板 | `#fffefa` | `#101010` / `#1b1b1b` |
| 侧栏、胶囊底 | `#eae9e5` / `#e9e7e1` | `#171717` / `#292929` |
| 细线 | `#d8d6d0` | `#303030` |
| 正文 | `#22211f` | `#ecebe8` |
| 次要文字 | `#716e68` | `#a7a5a0` |
| 主按钮（反色胶囊） | `#242321` 底 + `#fffdf9` 字 | `#eeece6` 底 + `#161616` 字 |
| 「相似与搭档」强调色 | `#13907e` | `#2aa391` |

- **五位顾问的头像色**：Steve Blank 蓝 `#1686fa`、Teresa Torres 青绿 `#00b9a9`、April Dunford 玫红 `#fc2ba2`、Bob Moesta 紫 `#9553fc`、Ash Maurya 橙 `#ff7100`。头像形状按 `avatarKit.js` 的定义。
- **书色**：按 `knowledge-warehouse.js` 的 `PALETTE`，由标题哈希决定。片中同一个作品的书色要和界面一致。
- **用色规则**：大面积只用纸色和黑色。彩色只出现在书、头像和「相似与搭档」的青绿色上，每个镜头最多一个彩色主角。

### 字体与版式

- **字幕和标题字**：思源黑体 / Noto Sans SC 加 Inter（都是 OFL 授权），粗体，字距略紧（约 -0.02em）。
- **章节小标签**：模仿界面上的 `LYDIA WORKSPACE`、`HACKATHON / 项目自述`，用小号大写，字距拉开。
- **不用斜体**：强调词改用颜色（白天 `#22211f` 上的强调色取 `#13907e`），不用 Ink Press 的衬线斜体。
- **最小字高**：按规则 Q11，字幕 ≥ 5% 帧高，辅助字 ≥ 3%。
- **界面截图的字体**：截图里的界面字体来自 Grok 应用素材（第三方，不进 git）。公开发布前，要么改用系统回退字体截图，要么先确认授权。见第 13 节待定项。

### 运动性格

- 稳，快进慢停，不加手持抖动（规则 Q3）。
- 每个镜头只有一个主要动作（P4）。
- 品牌字标落定后停 ≥ 1 秒，批量动作收尾留 0.5 秒静止（R1）。
- 全画面级的冲击全片 ≤ 3 处（R4）：T1 主题扫场、S09 光圈、S16 收场。

## 4. 总提示词（直接复制给制作 AI）

你是产品宣传片导演、Motion Designer 和合成师，使用 `C:\maven\business_agent\video\skill\video-shotcraft` 这个 skill，以「共同创作」模式工作。本文件第 1–3 节是已确认的产品简报和视觉方向，第 6–7 节是分镜。用户确认分镜后，从 `references/pipeline.md` 阶段 4 开始制作，不要重新设计已确认的内容。

**目标**：为 Lydia 做一支约 71 秒、1920×1080、30fps 的横屏介绍片。前半段讲数据库（资料怎么进来、怎么检查、怎么上架、怎么读原文），后半段讲商业逻辑（方法顾问接力、证据标签、人来选方向、一页商业模式）。节奏和质感参考同目录三份提示词，但视觉必须用 Lydia 自己的颜色、字体和真实界面。

**必须遵守**：
1. **镜头卡**：每个镜头先用 `gallery/api/library.json` 校验卡名和 style-key，完整读卡片 md，再按"参考实现"打开准确的 demo TSX。保留调校过的缓动、时值和"已知坑"参数，只替换素材、文案、坐标和颜色 token。不要凭卡名重写近似动画。
2. **真实界面**：真实界面一律用截图。先起本地 dev server，用无头浏览器截 2x 全页纹理、元素切片和 layout.json（`assets/scripts/capture-template.mjs`）。手搓 UI 只用于第 7 节标明"示意图"的镜头。
3. **数据库安全**：采集时只用**最新已验证备份的副本**起服务（`createApp({dataDir: <副本>, startWorker:false, localAutoLogin:true})`）。不碰正式库，不停也不重启 `Lydia Remote`。副本放在系统临时目录或 `data/data_storage/design-copies/`，用完删除，不能放进会进 git 的文件夹。
4. **画面里不能出现**：
   - 浏览器地址栏、Tailscale 主机名、邮箱、API key、Drive 文件夹 ID、本机路径；
   - 设置里的"连接"页；
   - 用户自己的研究、idea 和对话。
   商业逻辑段只用标"演示"的演示项目。
5. **数字和名字**：数字（作品数、新闻数）从采集用的副本当场读，不写死。作品的 finalist / 获奖状态是"上游声称"，不能说成已核实。
6. **专家**：只用 Lydia 自己的彩色小机器人头像，不用真人照片。出现专家名字的镜头，常驻小字"基于公开方法的 AI 顾问，不是本人"。
7. **动效偏好**：只要运动本身，不加星光、金尘、粒子、群发辉光、glitch、镜头炫光。高光一个镜头最多给主角一次（Q4）。
8. **确定性渲染**：不用 `Date.now()` 和 `Math.random()`，伪随机固定种子。
9. **交付**：带 BGM 版和无 BGM 版（保留 SFX）各一份，再加 `src/workbench.ts` 清单。交付前派一个干净上下文的 subagent，按 `references/final-review.md` 做独立终检，首检不交给用户。

## 7. 逐镜头提示词

### S01｜0:00.0–0:04.5（135f）钩子：每天都有新的……

- **镜头卡**：`pill-slot-cycle`（`demos/typography/pill-slot-cycle/PillSlotCycle.tsx`）
- **借鉴**：Holo 开场的大字连发，但不用渐变，只用纸底黑字。
