## 2. 直接复制使用的总提示词

你是一名专长于软件产品宣传片的导演、Motion Designer 和合成师。请依据我上传的参考视频，重建一支约 36–37 秒的横屏产品宣传片。请忠实匹配参考的镜头顺序、构图、标题节奏、卡片层级、运动方向和留白比例。不要只制作一支主题类似的通用科技广告。

### 视觉风格

采用克制的编辑设计风格：温暖的奶油白底、近黑色衬线主标题、低饱和棕金强调、浅色文档卡片、精细的界面线条、柔和投影与少量景深。整体像一本有空间感的研究手册或团队知识工作台。

主标题使用粗衬线字体；强调词改为棕金色斜体。小型功能标签和辅助说明使用细小的等宽或窄体文字，适当拉开字距。软件 UI 的正文遵循提供的真实截图。字体名称无法从低清参考准确确定，选择视觉接近的字体后，手动匹配字宽、字重和行距。

建议起始色板，仅供匹配参考时调整：背景 #F7F3ED，主文字 #1E1B17，强调色 #826326，浅线 #DCD5CA，卡片 #FFFDFA。不要把这些值当作原片取样结论。

### 运动语言

1. 主标题采用从左向右逐词显现，并让进入中的局部从模糊变清晰。禁止让整段文字长时间发糊。
2. 重要短语采用棕金色斜体，少量淡金底色与短细线强调。
3. UI 卡片作为独立平面图层存在于浅 3D 空间：正面可读，角度轻微，层间有厚度感和柔和投影。
4. 通过整体画布横移、卡片视差、由远到近的推镜，以及卡片堆叠/展开来衔接镜头。
5. 展示功能时遵循“总览→选中→细节→内容出现”，每段只保留一个明确焦点。
6. 相机始终平稳，进入快、停下柔和。避免夸张弹簧、手持抖动、持续转圈和过度透视。
7. 在标题页保留停顿，让观众读完，再进入实际界面。

### 内容与交付

原品牌版保留 AI Foundation Lab、TEAM RESEARCH CONSOLE 和参考中清晰可辨的主文案。替换为我的项目时，仅更换我提供的名称、真实界面、实际功能和文案，不推测项目名称，不添加尚未实现的能力。

生成前先给出逐镜头时间线和素材清单，再完成镜头。交付建议为 1920×1080、16:9、60fps、约 36–37 秒，这些是新制作的交付规格。主标题、UI、计数器和小字均需可编辑。若工具无法生成正确文本，先制作无字背景/卡片动画，再用文本层合成。没有清晰原始截图时，明确标记重绘或替代内容，不能声称恢复了原界面。

## 4. 运镜与效果的具体实现提示

### A. 文字从模糊到清晰

“把标题按词拆分，每个词先以低透明度、短距离位移和适度模糊进入；在约 0.2–0.4 秒内恢复清晰。后一个词比前一个稍晚进入。已经完成的文字不继续闪动。模糊揭示与阅读方向一致，标题位置始终稳定。”

这是制作建议，不是对原片插件的识别。需要在目标分辨率下调整模糊强度，不能机械照搬低清视频像素值。

### B. 棕金强调与细线

“主标题近黑色，关键词使用相同字体家族的斜体并改为棕金色。淡金底带只出现在参考有底带的镜头，不给每个强调词都加高亮。细线保持短、细、克制，用遮罩或缩放揭示，不用粗手绘笔刷。”

### C. 浅 3D 卡片与柔和阴影

“UI 卡片作为纹理清晰的独立平面，使用很小的旋转角度和深度偏移，形成轻微纸片感。光源大而柔，投影扩散、低对比，卡片与背景仍可区分。镜头停稳后文字应清晰，不能因为质感效果而牺牲正文稳定性。”

建议起始角度为约 3–10°，仅用于一般卡片；堆叠镜头需更明显的斜俯视。具体值按参考构图调整。

### D. 连续转场

“卡片墙→标题页：卡片退出或降低对比；标题页→卡片堆：让标题清场后进入深色空间；卡片堆→网格：维持卡片身份并移动到目标网格；网格→详情：目标卡片描边、推近、扩展为详情；功能界面→标题页：干净退场，留白后显字。避免每段都使用同一种交叉淡化。”

### E. UI 内容填充

“将输入字符、列表条目、计数器和文档段落视为独立可控状态。先设定每个状态的准确画面，再制作状态之间的动画。真实界面可使用录屏；重绘界面要保持布局、文字层级、对齐和字段语义。不要靠 AI 视频自动生成不断变形的 UI。”

## 5. 节奏与声音提示词

画面节奏为“品牌→总览→单卡价值→集中管理→堆叠展开→搜索与资料→Paper Radar→周报→团队协作→品牌收尾”。标题页与界面演示交替，是这支片的重要结构。

声音提示词：

“先读取原音并标记段落，再同步标题揭示、卡片展开、选中高亮、列表填充和尾版停顿。配乐与音效应克制、清楚、有节奏。仅在参考或新创作需求支持时添加轻柔滑动、细小点击、纸片移动等音效。未核对原音时，不声称这些音效来自原片。替代配乐需明确标注为替代，不虚构曲名或 BPM。”

## 7. 所需素材与验收

| 素材 | 用途 | 缺失时处理 |
| --- | --- | --- |
| 品牌文字、矢量标识、副标题 | 开场与收尾 | 用可编辑文字重建，确认拼写 |
| 项目网格与项目卡片 | 卡片墙、堆叠、展开、搜索 | 根据可读结构重绘，模糊小字不伪称原文 |
| 项目详情与关联文档 | 单卡进入与资料展示 | 使用实际功能截图或明确标注的示意界面 |
| Paper Radar 页面和条目 | 列表与计数 | 以真实资料填充，计数与条目对应 |
| 周报正文和侧栏 | 文档填充与团队协作 | 使用用户提供的示例内容 |
| 字体及使用许可 | 主标题、斜体、小标签 | 选视觉接近且可使用的字体 |
| 原音或替代配乐 | 节奏与声音 | 未核实原音时单独标记替代方案 |

交付完整成片与可编辑时间线，所有文字、卡片、计数器可修改。若使用代码动画，也需提供字体、图片、项目文件和明确的渲染方式；若使用剪辑/合成工具，提供工程和对应素材。

验收关注：奶油白是否一致；衬线字与斜体强调是否准确；标题断行是否接近；细线是否克制；卡片是否保持身份和层级；堆叠展开是否连续；搜索到详情是否有明确目标；计数是否与条目同步；周报文字是否稳定；品牌收尾是否有足够停留。

复刻接近度取决于这些可核对的元素。提示词负责描述目标，准确复现仍需要逐镜头关键帧、清晰素材与合成调整。
