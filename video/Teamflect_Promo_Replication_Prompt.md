## 一、可直接复制的总提示词

你是一名擅长 SaaS 产品宣传片的导演、Motion Designer 和 UI 合成师。请使用我上传的视频作为视觉与时间参考，逐镜头重建这段 Teamflect 风格宣传片。目标是还原可核对的镜头顺序、构图、色彩、对象运动、鼠标引导和卡片层级，不是只生成一支“科技感”广告。

### 视觉系统

以接近白色的浅灰背景为基础，搭配淡粉—浅紫渐变、白色圆角 UI、深紫导航栏和少量玫红品牌强调。背景包含大面积的圆角十字/拼接形块，呼应品牌符号。使用柔和接触阴影、轻微厚度、克制高光，形成干净的浅 3D 产品动画。

建议起始色板：浅底 #F7F7FA、浅紫 #C0B1EB、深紫 #6754B4、淡粉 #EBCDD7、玫红 #BF185A、近黑 #25242A。实际颜色应对照原片调整，不把建议值当成精确取色。

字体为现代无衬线，品牌字标较粗，UI 正文简洁紧凑。保留真实截图中的色彩状态标签、头像和进度条。低清小字无法辨认时使用用户提供的高清素材或明确标记的示意内容，不伪称恢复原文。

### 动画与运镜

整段由一个个浅 3D 信息场景组成，主要运动来自对象位移、相机推拉、横向平移和分层视差。镜头平稳，快进慢停，重要 UI 停稳后清晰。特写与总览交替，部分对象从画幅外进入，产生空间连续感。

重点保留以下效果：应用图标薄片叠层；品牌与设备左右布局；任务行阶梯展开；大号黑色鼠标指针；视频通话与绩效面板组合；评价模板堆叠与选择；发送面板；人物头像与岗位关系图；界面拼贴总览。

### 内容与输出

原品牌复刻保留 Teamflect、Microsoft Teams/Outlook 图标，以及能清楚辨识的主要文案。用于我的项目时，替换为我提供的品牌、真实集成、产品截图和实际功能；不自动假设项目名称，不把参考集成或绩效能力当成我的产品已实现功能。

建议制作规格：1920×1080、16:9、60fps，按这段有效素材约 15.5 秒编排。最终时长以清理录屏开头后的有效范围为准。该规格是交付建议，不代表原始广告规格。

请先输出分镜与素材清单，再逐镜头制作。主标题、UI、进度百分比、鼠标和线条都用可编辑图层或确定性动画制作。AI 视频只用于适合生成的背景/装饰素材；不要让模型猜测界面文字。

## 二、逐镜头复刻提示词

### 01｜约 00:00.5–00:01.4：产品信息拼贴总览

**参考观察**：中央为任务表格/软件页面，周围有数据块、文档、人物/团队条和细连接线；录屏刚开始时还有过渡模糊。

**提示词**：

“在浅白背景中排布多种产品信息模块：中心为横向任务表格，周围为文档摘要、数据卡和团队头像条。图层分布在不同深度，大小不同，细线建立模块之间的关系。相机快速但平稳地进入这个信息空间，开始有短暂运动模糊，停稳后界面恢复清晰。保留画幅边缘被裁切的模块，避免所有卡片等大排成平面墙。不要复制录屏叠层。”

**制作要点**：此处可能处于循环边界，不把开头模糊认定为原片刻意的独立开场特效。重建时允许保留短过渡，但不复制手机界面残影。

### 02｜约 00:01.4–00:02.9：Outlook / Teams 立体图标

**参考观察**：左下为 Outlook，右上为 Teams；白色圆角方片之下露出玫红、紫色和深色薄片，背景为浅粉紫光晕。

**提示词**：

“切入简洁的双应用图标场景。Outlook 白色圆角图标块位于左下前景，Teams 图标块位于右上后景。每个白色图标块下方露出两至三片偏移的玫红、紫色或深灰薄片，形成轻微厚度。相机斜俯视，图标整体小幅转向并缓慢靠近，柔和阴影落在浅色地面上。应用标志作为清晰的独立贴图出现，不能随角度变形。图标旁辅助小字仅在有清晰素材时复刻。”

**运动建议**：图标组轻微俯仰和偏航，幅度保持克制；薄片短距离错位移动，最后稳定叠放。不要将其做成复杂机械拆解。

### 03｜约 00:02.9–00:04.7：品牌与设备主视觉

**参考观察**：左侧 teamflect 字标和玫红图形，下面为 An All-in-One Performance Management Solution；右侧为黑边设备中的产品界面，背景有淡紫粉圆角形块。

**提示词**：

“建立左右主视觉：左侧为清楚的 teamflect 品牌字标和玫红符号，下方两行 An All-in-One Performance / Management Solution；右侧为黑边横向设备，屏幕展示真实产品首页。淡紫粉色圆角十字形块在背景中形成大面积装饰。设备从偏画外的位置平滑进入并稳定，底部有柔和接触阴影。轻微推近整个构图，字标始终清晰，设备保持正确透视。”

**衔接**：界面中的任务区域引导视线进入下一镜头的独立列表行。设备类型在低清素材中不作精确硬件型号判断。

### 04｜约 00:04.7–00:07.4：任务列表阶梯展开与鼠标引导

**参考观察**：多条细长白色任务行从一个条目扩展为阶梯阵列；每行含头像、标题、彩色状态、进度和日期，大号黑色鼠标在其间移动。

**提示词**：

“将任务列表拆成五至七条独立的白色细长 UI 行。先出现一条，再按节奏逐条进入，沿纵向和深度方向排列，形成向远处延伸的阶梯。近处行更大、更清晰，远处行稍小，所有行保持相似的轻微透视角度。每行包含头像、任务名称、彩色状态标签、进度条和日期。相机横向平移并小幅靠近，让观众沿列表浏览。大号黑色三角鼠标在状态和进度附近平滑移动，短暂停留引导视线。”

**制作要点**：鼠标是设计过的前景图层，不用系统鼠标录制替代。用真实数据控制状态变化；没有明确点击反馈时，不擅自添加大波纹、爆炸或每行自动完成。

### 05｜约 00:07.4–00:09.2：视频通话、应用入口与绩效侧板

## 三、核心特效的制作指令

### 1. 分层视差

“将每个 UI 元件独立分层，背景形块移动最慢，中景 UI 次之，前景鼠标和长卡片最突出。相机移动与图层反向位移二选一作为主方法，避免叠加后速度失控。需要停稳时所有主要文字恢复清晰。”

### 2. 圆角图标叠层

“图标主体由白色面板、应用矢量标志、两至三片偏移底片和柔和接触阴影组成。面板可有很薄的侧边，禁止做成厚重玩具积木。俯仰角随构图微调，标志保持正确比例。”

### 3. 列表阶梯

“每条任务行使用同一布局，沿深度与高度错开，形成近大远小的阵列。条目按约 0.08–0.15 秒错开进入作为起始值，运动先快后慢。选中反馈只发生在鼠标关注的目标，其他条目保持稳定。”

### 4. 鼠标编舞

“鼠标作为独立图层，设计路径和停顿点。移动时轻微加速，接近目标时减速；悬停时再出现按钮或提示。鼠标尺寸明显大于真实系统指针，跟随原片视觉比例，但不能遮住整行正文。不加入每次点击都弹出的波纹。”

### 5. 模板堆叠

“使用多个圆角卡片和固定的叠放间距，依次升起。每张卡片的顶部标题露出，目标卡片选择后圆形状态标记切成勾选。保持品牌色系，少量轻微角度即可，不用扑克牌洗牌式翻转。”

### 6. 连接线网络

“用矢量路径绘制连接线，先出现主干，再出现分支、节点和岗位胶囊；随后相机横向浏览。路径和卡片共用坐标系统，镜头移动时连接点不脱落。复杂拓扑由人工或数据结构控制，不使用视频生成模型随机补线。”

### 7. 建议运动参数

| 元素 | 建议起始值 | 调整目标 |
| --- | --- | --- |
| 主要对象进入 | 约 0.25–0.5 秒 | 快进慢停，避免拖沓 |
| 大号鼠标目标停留 | 约 0.15–0.35 秒 | 让观众辨认操作对象 |
| 一般 UI 角度 | 约 3–10° | 保持正文清楚 |
| 图标与模板错位 | 以面板尺寸比例控制 | 可见叠层但不散乱 |
| 快速运动模糊 | 只在过渡段使用 | 停稳后清晰 |
| 景深 | 前后层轻微区分 | 不把主要界面长期虚化 |

以上均为复刻起点，最终以参考关键帧的相对位置、速度、遮挡关系与停顿为准。
