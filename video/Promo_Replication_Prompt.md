# 参考宣传片逐镜头复刻提示词

## 使用说明与分析边界

参考：本次上传的 WhatsApp 视频，录屏总长约 44.66 秒。以下时间均对应上传文件的时间，按约每 0.5 秒的画面采样分析；切点为近似值，不是逐帧测量结果。

上传文件是 384 × 832 的竖屏录屏，真正的宣传片位于中间约 384 × 216 的横屏区域，约为 16:9。开头控制中心、外围黑边、状态栏、右侧账号/点赞按钮、下方文案都属于录屏或平台叠层，不应复刻进成片。平台叠层遮住的像素不能直接恢复，需重新制作。

主要视觉为白底、黑色无衬线字体、橙红—洋红—紫蓝渐变、柔和金属/玻璃质感、圆角 UI 卡片、空间漂浮、多语言标签、白色机器人、实拍设备合成。不是以实景摄影机运动为主，而是由文字缩放、图层位移、3D 旋转和视差制造运镜感。

以下对画面内容的描述来自参考视频；缓动曲线、焦距、帧率、粒子实现、运动模糊及时间长度细分属于复刻建议，不代表已确认原片制作参数。未核对原音逐拍位置和完整旁白，因此不提供假定的 BPM、歌词或逐字配音稿。

最接近原片的方式：按下面的镜头拆分重建，在可控的动画/合成时间线上排版文字和 UI；AI 视频用于机器人或背景等素材。不要指望一次文生视频准确生成全部文字、UI 和镜头衔接。

## 可直接交给制作 AI 的总提示词

你是一位产品宣传片导演、Motion Designer 和合成师。请把我上传的视频作为唯一的视觉和节奏参考，重建其横屏宣传片。目标是尽可能忠实地还原原片的构图、镜头顺序、视觉密度、文字节奏、转场逻辑和品牌质感。

先识别真正的视频画面，剔除手机录屏界面、控制中心、社交平台按钮、黑边和水印。不要把竖屏录屏尺寸当成最终画幅。输出建议为 1920×1080、16:9、30fps，成片约 44 秒；这些是新制作的交付设置，不是对参考原生规格的判断。分析阶段可以使用参考文件的绝对时间码，最终剪辑从第一帧有效宣传内容开始计时。

请遵守这些要求：

1. 先按镜头输出分镜和素材清单，再逐镜头生成或合成。每个镜头都写明起始构图、结束构图、运动方向、视觉焦点、转场衔接和时长。
2. 文字使用可编辑文本层；UI 使用提供的清晰截图、矢量或重新绘制的组件。禁止用视频模型凭空生成可读正文。参考画质不足时，不要臆造界面小字。
3. 同一字体系统、同一渐变色系统、同一圆角规范、同一机器人外观贯穿全片。
4. 大多数画面为纯白底。橙红、粉紫、蓝紫渐变只用于关键强调、光晕、3D 表面和局部背景，避免每一帧都过度堆满颜色。
5. 字体为接近参考的现代无衬线体，紧凑、清楚、视觉重量充足；根据参考逐字调整，不声称能从低清视频确定原字体名称。
6. 节奏为短文字冲击→业务场景→灵感拼贴→语言覆盖→品牌→输入→机器人→功能演示→自动运行→产出→真实设备→价值→网址。
7. 所有转场应由已有对象的形状、位置或缩放自然连接。保留原片的干净感，避免无依据地添加 glitch、镜头摇晃、镜头炫光或大面积粒子。
8. 若某项效果无法直接完成，明确提供该镜头的素材和合成步骤；不得将占位镜头当成完成作品。

### 品牌替换规则

如果要求原品牌复刻，保留参考中的 Holo、tryholo.ai 和原有可读主标题。如果用于我的项目，只替换品牌、网址、真实功能名称、产品截图和对应案例；保持镜头语法和节奏。不要自动假设项目名称，也不要加入我的产品尚未实现的功能。未提供真实数据时，原片末尾金额只作视觉参考，不得改成我项目的真实营收或用户指标。

## 时间轴与逐镜头提示词

### 01｜约 00:00.5–00:01.8：大字开场 You

参考画面：白底，从很小的彩色局部进入，出现占据画面的大字 You，字面具有红紫蓝渐变和浅色边缘。

提示词：
“纯白背景，一个极小的彩色字形局部快速放大，变成巨大的 You。采用可编辑 3D/伪 3D 字体，橙红与洋红正面、蓝紫边缘和轻微高光，局部掠过画幅边界。运动以对象缩放为主，镜头保持正面，结束时字形清晰、有冲击力。只在快速移动时添加适度运动模糊。”

制作建议：缩放由约 15% 到 115% 再收至 100%，快速减速；不加入多次弹跳。精确起止缩放以参考关键帧为准。

### 02｜约 00:01.8–00:03.5：You built / something 与条纹渐变

参考画面：白字位于红粉蓝渐变光晕中央；渐变区域出现竖直切片/柱状起伏，随后缩成圆角胶囊，主词为 something。尾部可见彩色小点散开。

提示词：
“中心生成橙红内核、洋红中层、蓝紫外缘的柔焦渐变区域。将同一个渐变划分为多条竖向切片，各片轻微错位，形成波浪般上下起伏的轮廓。中央白色文字按参考依次出现。渐变整体向中心收缩成圆角胶囊，文字稳定停留。胶囊随后解构为少量粉紫橙色小点，并衔接下一镜头。”

制作建议：用渐变预合成加条状遮罩和错位动画模拟，不必假设原片使用某一种特定插件。小点只出现在过渡瞬间。

### 03｜约 00:03.5–00:05.7：A business 手机与平台图标

提示词：
“把上一镜头的渐变扩展为背景。标题 A business 在画面上方形成，真实手部抠像和手机从下方进入，位于前景中央。圆角平台图标分布在手机两侧，前后距离不同，柔和阴影，轻微漂浮。前景手机、近处图标和远处图标使用不同移动速度制造空间视差。末尾手机与标题向画面外滑动，为白底拼贴镜头让位。”

制作建议：实拍手部、手机屏幕和图标分层合成；轻微俯仰即可，避免大角度绕背导致 UI 看不清。

### 04｜约 00:05.7–00:07.9：An idea / Worth knowing about 灵感卡片

制作建议：使用 3D 球体与独立标签层。不要把语言标签焊死在球体表面，也不要用随机字符充当语言。

| 主标题进入 | 约 0.25–0.45 秒，快进慢停 | 文字冲击清楚，不拖泥带水 |
| 卡片进入 | 约 0.35–0.65 秒，轻微错开 | 避免所有素材同时弹出 |
| 硬切/快速过渡 | 约 0.1–0.25 秒 | 维持短片节奏 |
| 普通卡片轻微旋转 | 约 2–6° | 保留可读性与空间感 |
| 环境慢推 | 每镜约 3–8% 画面尺度变化 | 实拍镜头有呼吸感 |
| 快速动作模糊 | 仅高速移动段开启，停稳后清晰 | 避免全片发糊 |
| UI 圆角 | 按参考形状统一，以卡片短边比例控制 | 保持视觉系统一致 |

不要把这些数值写成“原片参数”。最终以逐镜头关键帧、遮挡关系和节奏匹配为准。

## 声音制作提示词

“以参考原音为依据进行逐拍标记，先标出标题变化、机器人飞入、功能切换、开关开启、数字升起和尾版出现的位置，再将镜头切点对齐。根据参考实际存在的声音，安排简短 whoosh、轻点按、开关 click 和低频强调。声音服务画面，不为每个小图层都添加音效。若无法读取参考原音，请明确说明，不要编造原曲名、BPM 或旁白内容。若需要另配音乐，提供经授权的相近节奏音乐，并将其标为替代配乐。”

## 统一负面提示词

“不要手机录屏边框，不要社交平台界面，不要水印，不要低清放大伪装高清，不要乱码，不要变形 UI，不要随机生成品牌标识，不要不稳定的机器人脸，不要人物手指畸形，不要屏幕闪烁，不要持续镜头抖动，不要随意 glitch，不要夸张镜头炫光，不要长时间交叉淡化，不要全片重景深，不要多余机器人，不要把白底改成暗黑科技风，不要擅自改成竖屏，不要新增未经提供的功能、数据或宣传承诺。”

## 制作交付要求

交付：完整横屏成片、可编辑分镜时间线、逐镜头素材目录、缺失素材说明。保证文字和 UI 可以后续替换。视频生成段若文字不可控，交付干净背景与独立文字合成，不接受把错误文字烧录进成片。

先检查：是否全部去掉录屏叠层；是否镜头顺序一致；是否主标题位置一致；是否渐变材质统一；是否卡片运动方向一致；是否机器人一致；是否真实设备屏幕透视正确；是否尾版有充分停留。视觉接近度以这些项目为准，而不是只看“科技感”。
